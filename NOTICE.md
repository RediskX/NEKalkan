# Происхождение материалов

Код NEKalkan написан заново (C++17, без внешних библиотек). Таблицы и заголовки, не являющиеся оригинальным кодом:

| Материал | Источник |
|---|---|
| `src/streebog_tables.inc` | таблицы подстановок Стрибога по ГОСТ Р 34.11-2012; сгенерированы из значений стандарта |
| `src/gost_curves.inc` | параметры эллиптических кривых (Р 50.1.114-2016, Р 1323565.1.024-2019, КриптоПро); сгенерированы скриптом из значений стандартов |
| `src/rc2_table.inc` | таблица PITABLE из RFC 2268 |
| `src/native_types.h` | определения интерфейсов Native API компании «1С» (раскладка и порядок виртуальных методов совпадают с официальными заголовками платформы) |
| константы `KC_*`, `KCR_*`, коды ошибок | значения для совместимости с SDK НУЦ РК (`KalkanCrypt.h`); числа, не код |

Для проверки правильности реализации используются независимые эталоны: векторы стандартов, независимые реализации алгоритмов, libxml2 и
настоящая `KalkanCrypt.dll` из SDK НУЦ РК (в поставку не входят).
