# NEKalkan — константы

Все константы доступны как свойства объекта компоненты только для чтения (`Крипто.KC_SIGN_CMS`). Значения совпадают с SDK НУЦ РК (`KalkanCrypt.h`).
Дополнительно NEKalkan возвращает `WRAP_NOT_IMPLEMENTED` = `0x0A51000C` для методов, которых нет в этой сборке; в списке свойств этой константы нет.
